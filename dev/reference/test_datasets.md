# Datasets for testing

These datasets are used to test compatibility with foreign
(spss_foreign), or haven_2.0 (x_haven_2.0, x_spss_haven_2.0) packages

## Usage

``` r
x_haven_2.0

x_spss_haven_2.0

spss_file

dta_file
```

## Format

An object of class `haven_labelled` of length 6.

An object of class `haven_labelled_spss` (inherits from
`haven_labelled`) of length 10.

An object of class `list` of length 13.

An object of class `data.frame` with 47 rows and 6 columns.
